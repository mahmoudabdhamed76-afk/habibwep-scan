# مركز حبيب سكان | HABIB SCAN للأشعة والتحاليل الطبية

## محتويات المشروع
- `public/index.html`: الموقع الطبي المتكامل + بوابة استلام النتائج + لوحة التحكم (7 وحدات).
- `server.js`: خادم Node.js وواجهة `/api/state` لحفظ التعديلات وتقارير المرضى.
- `package.json` و `railway.json`: إعدادات التشغيل والنشر على GitHub و Railway.

## التشغيل محلياً (أو داخل Google Antigravity)
```bash
npm install
npm start
```
ثم افتح `http://localhost:3000`.

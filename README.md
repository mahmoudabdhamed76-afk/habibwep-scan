# Habib Scan (حبيب سكان) — مركز أشعة متطور

منصة ويب متكاملة لمركز **حبيب سكان** للأشعة والتشخيص الطبي المتطور:
- استعراض خدمات الأشعة والتصوير الطبي وتعليمات التحضير لكل فحص.
- حجز المواعيد إلكترونياً والحصول على رقم متابعة فوري.
- بوابة الاستعلام عن نتائج وتقارير الأشعة.

## التشغيل محلياً

```bash
npm install
npm start
```
